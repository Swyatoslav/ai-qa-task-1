# Task 7: Генерация и оценка тест-кейсов через Ollama

## Описание

Скрипт генерирует тест-кейсы для функции `calculate_discount()` с помощью трёх
различных промптов (через LLM из Ollama) и оценивает ответы по критериям:
- **Полнота** (0-6) — покрытие граничных значений и сценариев
- **Формат** (0-5) — структурная целостность ответа
- **Точность** (0-5) — верность ожидаемых результатов

Результаты сравнения записываются в `compare_answers_resuls.txt`.

## Структура проекта

```
task-7/
├── main.py                    # Основной скрипт
├── prompts.py                 # Три промпта для LLM
├── compare_answers_resuls.txt # Результат сравнения (создаётся при запуске)
└── README.md                  # Эта инструкция
```

## Три промпта

| # | Название | Особенности |
|---|----------|-------------|
| 1 | Полный формат + категории | Таблица, секции "Позитивные"/"Негативные", минимум 10 ТК |
| 2 | Минимальный | Без указания формата и категорий |
| 3 | Формат без категорий | Структура ID/Входные/Ожидаемый, без разделения на позитив/негатив |

## Требования

- Python 3.8+
- Ollama (https://ollama.com)
- Библиотека `requests` (обычно уже установлена)

## Установка Ollama

```bash
# macOS
brew install ollama
# или скачать с https://ollama.com/download

# Запустить сервис
ollama serve

# Скачать модель
ollama pull llama3.2
```

## Запуск

```bash
cd task-7
python3 main.py
```

Скрипт:
1. Проверяет доступность Ollama API на `localhost:11434`
2. Если модель `llama3.2` не найдена — использует первую доступную
3. Для каждого промпта вызывает Ollama (`/api/generate`, stream=False)
4. Оценивает ответ по трём критериям
5. Записывает отчёт в `compare_answers_resuls.txt`

## Настройка

В `main.py` можно изменить:

```python
OLLAMA_HOST = "http://localhost:11434"  # адрес Ollama
MODEL = "llama3.2"                      # модель
TIMEOUT = 120                           # таймаут в секундах
```

## Критерии оценки (детали)

### Полнота (макс. 6 баллов)
| Сценарий | Балл |
|----------|------|
| Обычный (позитивный) случай | 1 |
| Граница: discount_percent = 0 | 1 |
| Граница: discount_percent = 100 | 1 |
| Отрицательная цена (price < 0) | 1 |
| discount > 100 | 1 |
| Отрицательный discount (discount < 0) | 1 |

### Формат (макс. 5 баллов)
| Элемент | Балл |
|---------|------|
| Структурированное представление (таблица/список) | 1 |
| Идентификаторы тест-кейсов | 1 |
| Разделение на секции | 1 |
| Поле "Ожидаемый результат" | 1 |
| Поле "Входные данные" | 1 |

### Точность (макс. 5 баллов)
Если удалось извлечь пары `(price, discount)` — выполняется верификация
через реальное исполнение функции. Если нет — оценка по наличию корректных
сообщений об ошибках и формулы расчёта.

## Ожидаемый вывод

Файл `compare_answers_resuls.txt` содержит:
- Сводную таблицу с баллами по каждому промпту
- Детализацию по каждому критерию
- Отрывок ответа LLM
- Вывод с рекомендациями
