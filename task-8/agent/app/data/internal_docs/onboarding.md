# Onboarding for QA Engineers

Добро пожаловать в команду QA!

## Первый день

1. Получите доступ к TMS TestOps.
2. Ознакомьтесь с QA Guidelines.
3. Настройте локальное окружение по инструкции из репозитория.

## Инструменты

- TMS TestOps — управление тест-кейсами и запусками.
- Autotests — pytest + Playwright.
