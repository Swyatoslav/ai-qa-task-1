**1. Позитивный тест регистрации**
#### ID: 1
#### Название: Регистрация пользователя с правильными данными
#### Тип: Позитивный
#### Предусловия: Открыта страница формы регистрации.
#### Шаги:
  1. Ввести в поле "Имя пользователя" значение "user123".
  2. Ввести в поле "Пароль" значение "Password123!" и убедиться, что пароль маскируется.
  3. Ввести в поле "Подтверждение пароля" значение "Password123!".
  4. Нажать кнопку "Зарегистрировать".
#### Ожидаемый результат: Пользователь успешно зарегистрирован.
