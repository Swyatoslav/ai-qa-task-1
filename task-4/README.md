# Task 4: Бот для управления web-сервером

Скрипт `web_server_bot.py` — интерактивный бот, который принимает путь к JSON-файлу
с документацией и отвечает на вопросы пользователя согласно ей.

## Файлы

| Файл | Описание |
|------|----------|
| `doc.json` | Документация в формате JSON (вопрос → ответ) |
| `web_server_bot.py` | Скрипт-бот, принимающий `--doc <путь>` |
| `dialogue_example.md` | Пример диалога с ботом |

## Установка зависимостей

Скрипт написан на Python 3 и **не требует внешних зависимостей** —
используются только стандартные модули (`argparse`, `json`, `re`, `sys`).

Требуется Python 3.6+.

```bash
python3 --version
```

## Запуск

```bash
python3 web_server_bot.py --doc doc.json
```

Параметр `--doc` — путь к JSON-файлу с документацией.

Формат JSON-файла:
```json
{
  "вопрос пользователя": "ответ бота",
  ...
}
```

Бот переходит в интерактивный режим. Задавайте вопросы и получайте ответы.
Для выхода введите `exit` или нажмите `Ctrl+D`.
