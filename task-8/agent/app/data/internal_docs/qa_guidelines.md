# QA Guidelines (Internal)

## Общие правила тестирования

1. Каждый тест-кейс должен иметь предусловие и шаги.
2. Используйте приоритеты: Low, Medium, High, Critical.
3. Баг-репорты должны содержать шаги воспроизведения, ожидаемый и фактический результат.
