# Пример диалога с ботом

Ниже приведён пример сессии взаимодействия с ботом `web_server_bot.py --doc doc.json`,
демонстрирующий корректные ответы на различные вопросы.

---

```
$ python3 web_server_bot.py --doc doc.json
Загружено вопросов: 8 (файл: doc.json)
Задайте вопрос (или 'exit' для выхода):

Вы: Как запустить сервер?
Бот: Для запуска сервера выполните команду:
  python web_server.py --port 8080

Флаг --port указывает порт, на котором будет слушать сервер (по умолчанию 8080).

Вы: Порт занят, что делать?
Бот: Если порт занят, используйте другой порт:
  python web_server.py --port 9000

Флаг --port принимает любой свободный порт.

Вы: Как включить логирование?
Бот: Логирование включается флагом --log-level <log_level>:
  python web_server.py --port 8080 --log-level info

где log_level — уровень логирования (например: debug, info, warning, error).

Вы: Как остановить сервер?
Бот: Остановить сервер можно командой:
  kill <pid>

где pid — ID запущенного процесса web-сервера. Узнать PID можно, например, командой: ps aux | grep web_server.py

Вы: Что такое pid?
Бот: pid — это ID запущенного процесса web-сервера. Команда остановки: kill <pid>

Вы: Полная инструкция по управлению сервером?
Бот: Инструкция по управлению web-сервером:

1. Запуск сервера:
   python web_server.py --port 8080

2. Если порт занят:
   python web_server.py --port 9000

3. Логирование:
   python web_server.py --port 8080 --log-level <log_level>

4. Остановка сервера:
   kill <pid>

где:
   - pid — ID запущенного процесса web-сервера
   - log_level — уровень логирования

Вы: exit
Пока!
